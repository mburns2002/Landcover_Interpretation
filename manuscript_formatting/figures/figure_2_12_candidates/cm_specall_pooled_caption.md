# Caption: Spectral Composite confusion matrix (Figure 2.12 candidate)

Spectral Composite, all sensors all indices. Ten-class confusion matrix for the spec_all classifier
(Sentinel-2, Landsat 8, and Sentinel-1 raw bands and indices, 50 bands), pooled over 168 cells against
the adjudicated interpreted reference. Reference classes are on the rows and predicted classes on the
columns. Cells are raw pixel counts colored by the row proportion, so the diagonal shade is the
producer's accuracy for that class. The PA column is producer's accuracy (recall) with the reference
support n (row totals), the UA row is user's accuracy (precision) with the predicted support n (column
totals), and the corner gives overall accuracy and Cohen's kappa. Overall accuracy is 59% and kappa is
0.46.
