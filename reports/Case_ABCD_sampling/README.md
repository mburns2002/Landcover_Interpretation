# Case_ABCD_sampling

Monte Carlo characterization of **sampling designs** against a known census, for the landscape-change
maps (embedding variants v2 to v6) scored on the interpreter-labeled reference cells.

> **These are draws from designs whose statistical properties we characterize, not accuracy
> estimates.** The census (every valid window in every cell) is treated as ground truth here; the
> question is how fast, and whether, a *sampled* estimate reaches that census, and what a given
> design costs in precision.

Generated by `scripts/sampling_experiment_ABCD.py`. The 5-class collapse lives in the sibling
directory [`../Case_ABCD_sampling_5class/`](../Case_ABCD_sampling_5class/).

---

## What the experiment does

1. **Population.** For each reference cell and window size `W`, take the exhaustive non-overlapping
   `W x W` tiling (window positions `i*W, j*W`), keeping windows whose center pixel is jointly valid
   (reference and model class both in 1..10). Pool these across all cells into one finite population.
   The cell is a simple random draw from the `grid_112_naip_brackets` frame, so the cell is the
   primary sampling unit and its pixels are a census.
2. **Sample.** Draw `n` distinct windows without replacement (so sampled windows never overlap),
   `100` iterations per `(n, W, design)`. The **stratum** of a window is its center pixel's reference
   class (10 strata).
3. **Compare** the sampled estimate to the full-population census, per approach, per design.

**Grid searched:** `W in {1, 3, 5, 7, 9}`, `n in {20, 50, 100, 200, 500, 1000, 2000, 5000}`
(total across the pooled frame, not per cell), variants `v2..v6`, `100` iterations, base seed `42`.

### Two designs
- **Simple random** — `n` windows uniform from the pool. Self-weighting and unbiased for the census,
  but expected to miss rare classes at small `n` (documented in `class_absence.csv`, not hidden).
- **Stratified** on the center reference class, equal allocation `n/10` per stratum. If a stratum has
  fewer windows than its allocation, take all of it and record the shortfall. Estimators are
  Horvitz-Thompson (window weight `N_h / n_h`). Both the **weighted** estimate (converges to the
  census) and the **unweighted** one (stays biased) are reported so the gap is visible.

### Four approaches (window aggregation)
| | approach | what it counts |
|---|---|---|
| **A** | per-pixel | pool all `W^2` pixels of the sampled windows into one confusion matrix (no aggregation) |
| **B** | dominant pair | the dominant (map, ref) pair per window; ties broken by lowest map then lowest ref code |
| **C** | plurality | the plurality class per field independently; also the fraction of windows whose plurality was a true majority |
| **D** | proportions | per-class `prop_map` vs `prop_ref`; **correlation** is the primary tightness metric (rmse and bias reported alongside, since rmse rewards predicting near-zero for rare classes) |

At `W = 1`, A, B, and C collapse to the same per-pixel quantity; the script asserts this as a
correctness check.

## Regenerate

```bash
# 10-class, this run (adjudicated reference + per-bracket predictions)
python scripts/sampling_experiment_ABCD.py \
  --truth exports/truth_selections.csv --preds data/raw/transfer_predictions

# 5-class collapse (writes to ../Case_ABCD_sampling_5class/)
python scripts/sampling_experiment_ABCD.py --collapse \
  --truth exports/truth_selections.csv --preds data/raw/transfer_predictions

# redraw the plots from the existing CSVs, without re-sampling
python scripts/sampling_experiment_ABCD.py --plots-only

# the extra comparison plots
python scripts/sampling_variant_comparison.py     # variant_comparison, variant_separation_scatter
python scripts/sampling_collapse_comparison.py     # 5-class change_convergence, collapse_summary, ...
```

Useful flags: `--versions`, `--ws`, `--ns`, `--iters` to narrow the grid; `--plots-only` to rebuild
figures from CSVs. Requires `rasterio`, `numpy`, `pandas`, and `matplotlib`.

## Reading the results (the headline findings)

- **Precision scales as `1/sqrt(n)`**, but each window is worth less than its pixel count because of
  spatial autocorrelation. The design effect is large for the coherent variants (v2 to v5) and near 1
  for the near-independent, fragmented v6.
- **Simple random misses the rare change classes** at small `n`; a stratified design is needed to
  guarantee they appear.
- **Stratification is a trade:** it lowers variance on the rare classes and raises it on the common
  ones. Only the **weighted** stratified estimator returns to the census; the unweighted one stays
  biased because equal allocation over-samples the rare strata.
- **Per-class proportion agreement (D)** stabilizes fast for common classes and stays low and noisy
  for the rare change classes even at the largest `n`.
