# GLKN_change_agents

Per-year exploratory summaries of the GLKN attributed change-agent polygons, one file per NAIP target
year (2017 to 2020). Source: the shared Google Drive folder `GLKN_GRID_CHANGE_ANALYSIS`, pulled
2026-07-26 (originals also in `data/raw/glkn/change_analysis/`).

## Files
`glkn_eda_changeagents_<year>.csv` — one row per change agent, with polygon-area statistics for that
year's attributed polygons.

## Columns
| column | meaning |
|---|---|
| `system:index` | Earth Engine row index |
| `agent` | change agent: `harvest`, `development`, `beaver`, `insect_disease_mort` |
| `n_polys` | number of attributed polygons |
| `total_m2` | total polygon area (square meters) |
| `mean_m2`, `median_m2`, `min_m2`, `max_m2` | per-polygon area statistics (square meters) |
| `year` | NAIP target year |
| `.geo` | geometry field, empty here (MultiPoint with no coordinates) |

These look like Earth Engine aggregation exports (area stats per agent per year), useful for
describing how much of each change type is present in the GLKN reference by year.

## Grid-proportions table
`glkn_grid_proportions_per_agent_5070_4agent.csv` (from the shared `GLKN_grid_analysis_7_26_26`
folder, pulled 2026-07-27) counts, at five square grid-cell sizes, how many cells contain each change
agent. EPSG:5070 (CONUS Albers); cell sides 420, 840, 1680, 3360, and 6720 m (14 to 224 px at 30 m).

| column | meaning |
|---|---|
| `agent` | change agent: `harvest`, `development`, `beaver`, `insect_disease_mort` |
| `cell_side_m`, `cell_side_px` | grid-cell side length in meters and pixels |
| `n_cells_total` | total grid cells at that size |
| `n_cells_complete` | fully-within-frame cells at that size |
| `n_with_change` | cells containing at least one polygon of this agent |
| `.geo` | empty geometry field |

## Polygon-size summary and histograms (2010 to 2020)
Pulled from Drive 2026-07-27, watershed-scoped, all four agents including beaver:
- `glkn_polygon_area_by_agent_2010_2020.csv` — one row per agent with `n_polys`, `min_m2`,
  `median_m2`, `mean_m2`, `sd_m2`, `max_m2`, and `total_m2`. Backs the Chapter 3 polygon-size table.
- `glkn_histograms_by_agent_2010_2020.csv` — one row per polygon with `agent`, `area_ha`, `area_m2`,
  `log10_area_ha`, and `year` (10,169 polygons). Backs the polygon-size distribution figure.

## Chapter 3 tables
Built by `scripts/build_chapter3_tables.py` into `manuscript_formatting/tables/` (CSV, PNG, and DOCX
each): `chapter3_table_detection_rate_by_cell_size`, `..._complete_cell_counts_by_cell_size`, and
`..._polygon_size_by_agent`. Sources: the grid cell-size CSV (Tables A and B) and
`glkn_polygon_area_by_agent_2010_2020.csv` (Table C, with median and standard deviation).
