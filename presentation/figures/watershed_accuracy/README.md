# watershed_accuracy — accuracy inside vs outside a GLKN watershed

Splits the 180 interpreted cells by whether their center falls inside one of the seven GLKN park
watersheds (13 inside, 167 outside) and compares per-class F1 (5-class collapse, model vs the adjudicated
interpreted reference), pooled over each group. Generated by `presentation/scripts/pres_watershed_accuracy.py`
(reuses `model_class_ci_5class.cell_confusions` for the confusions and the watershed shapefile for the split).

- `watershed_accuracy_per_class_f1.png` — grouped bars, inside vs outside, per class, for the v2
  classifier (representative embedding).
- `watershed_accuracy_per_class_f1.csv` — the full table for every source: per-class F1 inside and
  outside, the difference, and per-class reference support for each group.

## Finding

Per-class accuracy is essentially the same inside and outside the watersheds. For v2, Stable is 0.95 vs
0.93 and Harvest 0.13 vs 0.12; the other change classes are at the floor in both groups. Differences are
small (mostly < 0.06) and not consistent in sign across the six sources, so there is no watershed effect
on accuracy. Caveat: the inside group is only 13 cells, so the change-class values rest on few pixels
(Insect/Disease has ~no inside support, hence 0.00 inside for several sources) — read the support columns
in the CSV.
